# LKOS
Code for my paper "On the Dependence Structure of the Largest k Order Statistics" (Heinonen and Neslehova, 2026) 
Available as preprint: 

LKOSsourceCode.R contains all relevant functions related to the k-extremal copula. Includes generating samples from the k-extremal copula and goodness-of-fit testing the k-extremal copula via the Rosenblatt Transform.  

aixDataAnalysis.R contains my code for the data illustration (section 4).
